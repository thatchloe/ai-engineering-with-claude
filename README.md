# AI Engineering with Claude

Coursework and projects for the AI Engineering with Claude program.

## Courses

- [Harness Engineering with Claude](harness-engineering-with-claude/) — agentic loops, context strategy, Claude Code configuration, and Layer 3 orchestration, plus the capstone (`Project-Harness Engineering with Claude and Claude Code/`).
- [MCP in Action](mcp-in-action/) — the Model Context Protocol: a custom Firecrawl scraper server, SQLite and filesystem servers, and a Claude tool-use client, plus the capstone (`Project-PriceScout Agentic Analyst/`).
- [Agent Evaluation & Observability with Claude](agent-evaluation-observability-with-claude/) — validated retry with escalation, schema-enforced two-pass extraction, and provenance-preserving multi-source synthesis, plus the capstone evidence pack (`Project-Evaluation and Observability Project/capstone-submission/`).
